# 원소실

브라우저에서 실행하는 2D 가상 화학 실험실입니다. 용액 농도·이온·고체·방출 기체를 추적하는 교육용 이상용액 모델입니다. 적용 범위와 상수는 [과학 모델](docs/SCIENCE.md)을 확인하세요.

## 실행

Node.js 22.12 이상(권장 24)에서 실행합니다.

```sh
npm ci
npm run dev
```

터미널에 표시된 로컬 주소를 브라우저로 여세요. ES 모듈을 사용하므로 `file://` 직접 실행은 지원하지 않습니다.

## 검증과 배포

```sh
npm test
npm run build
npm run preview
```

`dist/`의 내용을 정적 호스팅에 배포합니다. 상대 자산 경로를 사용하므로 하위 경로 배포도 가능합니다. 빌드 없이 HTTP 서버로 원본을 제공할 때는 `index.html`, `styles.css`, `app.js`, `model.js`가 모두 필요합니다.

### Docker Compose 배포

루트의 `docker-compose.yml`로 실행합니다.

```sh
docker compose up -d --build
```

`web` 서비스는 Node.js로 빌드한 정적 파일을 Nginx의 컨테이너 포트 80에서 제공합니다. `science26.public=true` 라벨을 붙여 공개 대상으로 지정했으며, 호스트 포트는 배포 플랫폼이 연결하도록 고정하지 않았습니다.

현재 프로젝트에는 별도 API 서비스가 없어 `science26.api=true` 라벨을 붙일 서비스가 없습니다. DB·Redis 서비스도 포함하지 않습니다. 현재 정적 앱에서는 자동 주입되는 `DATABASE_URL`·`REDIS_URL`을 사용하지 않으며, 이 연결 정보를 브라우저 번들에 포함하지 않습니다.

로컬 브라우저에서 컨테이너를 확인하려면 다음처럼 임시 포트를 연결할 수 있습니다.

```sh
docker compose run --rm --build -p 8080:80 web
```

브라우저에서 `http://localhost:8080`을 엽니다.

## 기능

- 물질 클릭·드래그 투입, 도구 생성·선택·이동·Backspace 삭제
- 가이드 실험 5종, 퀴즈 3종, 세션형 현상 도감 8종
- 농도와 물의 자동 이온화를 이용한 25°C pH, 부피·잔류 질량·방출 기체 누적량 표시
- 이온 기반 중화·침전, 산과 탄산칼슘·산화칼슘·수산화칼슘·아연 반응
- 수산화칼슘/염화은 용해 평형, 소금·설탕의 고체/용존량 구분
- 실제 경과 시간과 누적 전하량에 따른 물 전기분해
- 건조 CaCO₃/CaO 가상 가열로, 실온까지 냉각, 최대 30개 조작 되돌리기

물/증류수는 회당 100 mL, 수용액은 0.010 M·100 mL, 고체는 0.001 mol입니다. 전기분해 가이드는 황산나트륨 수용액을 사용하며 전원을 켠 후 잠시 기다려야 기체가 생성됩니다. 염화물 등의 혼합물은 전류 추정만 제공하고 경쟁 전극 반응에 따른 생성물 계산은 중지합니다.

도구는 최대 6개, 도구당 투입은 최대 200회이며 로그는 최근 200개를 유지합니다. 가열·냉각은 동시에 한 도구에만 적용하고, 전기 공급은 도구마다 독립적으로 유지합니다. 키보드는 Enter/Space로 도구 선택, 방향키로 이동합니다.

수용액은 25°C 항온 조건입니다. 증발·끓음·고온 혼합을 지원하지 않으므로 수용액 가열과 뜨거운 시료에 물 투입을 제한합니다. 지원하지 않는 반응 조합은 투입 전에 이유를 표시하고, 계산 범위를 벗어나는 pH·전류는 `—`로 표시합니다.

초기화·실험 변경·되돌리기는 이미 해금한 도감을 유지합니다. 새로고침하면 모든 세션 상태가 사라집니다. 영구 저장·여과 기능은 없습니다. 구조는 [아키텍처](docs/ARCHITECTURE.md), 수정과 검증 결과는 [검토 보고서](docs/REVIEW.md)에 정리되어 있습니다.

## 태블릿 사용

700–1366px 화면에서는 실험대와 시약을 왼쪽, 실험 선택·조작을 오른쪽에 표시합니다. 가로·세로 회전에 맞춰 시약 열 수와 실험대 높이가 바뀌고, 긴 실험 설명은 조작 버튼 위에서 별도로 스크롤됩니다. 700px 미만의 좁은 분할 화면에서는 조작 버튼을 화면 하단에 고정합니다.

시약은 선택한 도구에 탭으로 투입합니다. 도구 본체를 탭해 선택하고 상단의 **잡고 이동** 손잡이를 끌어 위치를 바꿉니다. 본체에서는 페이지 스크롤이 가능하며, 자유 실험의 **선택 도구 삭제** 버튼으로 키보드 없이 도구를 제거할 수 있습니다. 삭제·이동은 되돌리기로 복원할 수 있습니다.
