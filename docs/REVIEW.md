# 수정·검증 결과 — 2026-10-27

## 수정 결과

기존 검토에서 발견한 오류에 대해 계산 로직을 교체하고 지원 범위를 명시했습니다. pH·전류를 단순한 임의 지표로 계산하던 방식은 제거했습니다. 실제 실험의 모든 반응·속도를 예측하는 범용 시뮬레이터는 아니며, 구체적인 식과 가정은 [과학 모델](SCIENCE.md)에 있습니다.

| --- | --- |
| 전압만 켜면 물이 즉시 전량 분해 | 실제 경과 초·추정 전류를 적분하고 패러데이 법칙으로 기체 생성. 물 소모·전하·시간 표시 |

| HCl·고체 소금의 Cl⁻가 AgCl 침전에 참여하지 않음 | 이온 기반으로 변경, 출처에 관계없이 Ksp 평형 계산 |

| 물을 1000°C까지 액체로 유지 | 수용액은 25°C 항온. 가열·고온 물 혼합 제한. 건조 CaCO₃/CaO만 가상 가열로 지원 |
| 반응을 한 번만 순회해 연쇄 처리 누락 | 용해·중화·산과 고체 반응·평형을 수렴할 때까지 반복 |

| undo에 새 상태가 빠지거나 타이머가 남을 위험 | 도구 전체 deep clone, 복원 시 전기·가열 타이머 재구성 |

| 긴 시약 표기·초기 도구가 모바일 화면을 벗어남 | 줄바꿈·최소 폭 처리·도구 위치 제한 |

수정된 조합도 가정이 있습니다. 전도도는 무한희석 이온 몰전도도 근사이며, pH는 활동도를 농도로 간주합니다. 금속 이온 가수분해·탄산 평형·고농도·복합 반응의 전체 해를 구현하지 않았으므로 지원 범위 제한을 적용했습니다. 열분해 825°C는 시연용 전환 기준으로 유지하며 실제 분해 온도·속도로 일반화하지 않습니다.
