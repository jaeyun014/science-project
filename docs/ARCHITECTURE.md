# 현재 아키텍처

| 경로 | 책임 |
| --- | --- |
| index.html | 화면 골격, 모델 가정/계산 범위 설명, 도감 dialog |
| styles.css | 반응형 레이아웃과 실험 애니메이션 |
| model.js | 물질·이온 데이터, 투입량, 반응·용해 평형, pH·전류·질량, 전기분해와 범위 판정 |
| app.js | 도구·세션·가이드·도감, 조작·기록·undo, 타이머, DOM 표시 |
| tests/model.test.js | 계산 기준값, 보존 법칙, 지원 범위, 물질 쌍별 회귀 검사 |
| tests/lab.test.js | 실제 앱 로직과 가짜 시계로 가이드·타이머·undo·제약 검사 |
| docs/SCIENCE.md | 모델 상수·식·가정·한계·출처 |
| package.json / package-lock.json | Vite와 재현 가능한 의존성 설치 |
| dist/ | 빌드 산출물. 원본을 빌드해 생성하며 직접 수정하지 않음 |
| node_modules/, .vite/ | 의존성 및 캐시 |

UI → 범위 검사 → 진행 중 전기분해 시간 정산 → 상태 스냅샷 → model.addDose/react → 도감·가이드 재판정 → render 순서로 처리합니다. 모델은 DOM·타이머에 접근하지 않아 Node에서도 직접 테스트할 수 있습니다.

각 도구는 contents, gases, doses, used, occurred와 온도·전압·전하·시간을 독립적으로 가집니다. 가이드 완료는 입력 이벤트 순서 대신 투입량·반응 이력·현재 상태로 판정합니다. 회차 중 해금한 도감은 초기화와 undo 후에도 유지합니다. undo는 structuredClone으로 도구 상태 전체를 복원하고 가열·전기 타이머를 재구성합니다.

가열·냉각 타이머는 전체에서 하나이며 전기 타이머는 전원이 켜진 모든 도구를 갱신합니다. 전기 시간은 Date.now 차이로 계산하고, 시료 조작 직전에도 정산합니다. 도구의 바깥 DOM은 타이머 갱신 때 재사용하므로 포인터 캡처·포커스가 유지됩니다. 드래그와 키보드 이동도 undo 대상입니다.

도구 6개, 도구당 투입 200회, 이벤트 최근 200개, undo 30개로 세션 비용을 제한합니다. 서버 API·데이터베이스·영구 저장은 없습니다. VM 통합 테스트는 DOM을 대체하므로 실제 UI 검증은 별도로 수행합니다.
