# 태블릿 사용 및 검증 — 2026-11-02

700–1366px에서는 실험대·시약과 실험 선택·조작을 좌우로 배치합니다. 우측 설명 영역은 내부 스크롤되고 조작 버튼은 계속 접근할 수 있습니다. 화면 폭에 따라 시약을 3/4열로 표시하고, 낮은 가로 화면에서는 시약과 실험대 높이를 줄입니다. 700px 미만 분할 화면은 상단 실험 선택, 하단 고정 조작바를 사용합니다.

- 주요 버튼과 선택 입력 최소 높이 48px, 도구 이동 손잡이 높이 44px.
- 도구 본체 탭으로 선택, 시약 탭으로 투입. 터치에서는 손잡이로만 이동하며 본체 쓸기는 페이지 스크롤에 사용.
- 자유 실험의 선택 도구 삭제 버튼 추가. 이동·삭제는 기존 되돌리기로 복원.
- 타이머 갱신 때도 이동 손잡이 DOM과 포인터 캡처를 유지.
- 도감 닫기 버튼 확대. 좁은 화면은 도감 목록을 가로 스크롤로 배치.
- 알림이 태블릿의 우측 조작 버튼을 덮지 않도록 위치 조정.

검증: `npm test` 30/30 통과, `npm run build` 통과. 터치 본체/손잡이 구분·이동·취소·되돌리기 회귀 검사를 추가했습니다.

Chrome 화면 크기 조절로 768×1024 세로, 1024×768 가로, 820×1180, 1180×820, 640×960 분할 화면과 320px 좁은 화면을 확인했습니다. 가로 넘침이 없고 주요 버튼 높이가 최소 48px였습니다. 1024×768의 가이드 모드에서는 실험대 하단과 우측 조작 버튼이 화면 안에 들어왔습니다. 세로 화면에서 도구가 실험대 안에 유지됐고, 640px에서는 하단 조작바·가로 스크롤 도감이 표시됐습니다.

실제 브라우저에서 중화 실험 완료(pH 7.0), 자유 실험 도구 생성·선택·삭제·되돌리기, 도감 열기·닫기를 확인했습니다. 수집된 error 로그는 0건이었습니다. 실제 iPad/Android 태블릿 하드웨어와 Safari의 터치 제스처는 별도 검증하지 않았습니다.
